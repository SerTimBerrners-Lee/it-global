# it-global

Сайт IT Global — услуги внедрения корпоративных сервисов на инфраструктуре клиента.

Статический сайт на HTML, CSS и JavaScript без сборки и серверных зависимостей.

## Возможности

- Каталог решений для почты, задач, CRM, ERP, базы знаний, файлов и совместной работы.
- Калькулятор расходов и окупаемости перехода.
- Выбор сервисов и подготовка заявки.
- Адаптивная версия для компьютеров и телефонов.

## Локальный запуск

Из корня репозитория:

```sh
python3 -m http.server 8000 --directory dist
```

Откройте http://localhost:8000. Для JavaScript-модулей нужен HTTP-сервер; открытие HTML как локального файла не подходит.

## Структура

- `dist/index.html` — страница сайта.
- `dist/styles.css` — оформление и адаптивная вёрстка.
- `dist/app.js` — каталог, формы и интерактивные элементы.
- `dist/services.js` — описания сервисов и условия их использования.
- `dist/calculator.js` — расчёт экономии и окупаемости.
- `dist/config.js` — название и email для заявок.
- `dist/assets/` — изображения и шрифты.

## Заявки

Пока `contact.email` в `dist/config.js` равен `null`, форма скачивает заявку в текстовый файл. После добавления адреса форма открывает почтовое приложение пользователя с подготовленным письмом. Автоматической отправки через сервер нет.

## Размещение

Опубликуйте содержимое `dist/` на статическом хостинге. Команда сборки не требуется.
